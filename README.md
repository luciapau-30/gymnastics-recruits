# 🤸 NCAA Gymnastics Recruit Database (2024–2027)

Join the fun here!! : https://gymnastics-recruits-ohrtqszxjbcf5voognscce.streamlit.app/

A Python + Streamlit project that tracks and analyzes NCAA gymnastics recruits, integrating **data pipelines, ranking algorithms, and an interactive dashboard**.

If we have it for Football, why not for gymnastics?! 

Built to showcase SWE + data engineering skills through a real-world dataset of **500+ athletes**, compiled with more gym-fans!

---

## ✨ Features
- **Data Cleaning Pipeline**
  - Converts raw recruit data into clean, structured CSVs.
  - Handles missing scores, inconsistent names, and duplicates.
- **Recruit Database**
  - Tracks Level 10 & Elite gymnasts across USA schools, regions, and years.
  - Includes Event scores when available. 
- **Athlete Rating Algorithm**
  - Custom ranking system using event high scores (VT, UB, BB, FX), All-Around averages, and  Perfect 10.0s.
- **Interactive Dashboard**
  - Built with **Streamlit** for real-time exploration.
  - Filters by region, level, and school.
  - Displays top 10 recruits, distributions, and rankings.

---

## 🛠 Tech Stack
- **Python 3.13**
- **Pandas** for data analysis
- **Streamlit** for the web dashboard
- **Plotly/Matplotlib** for visualization
